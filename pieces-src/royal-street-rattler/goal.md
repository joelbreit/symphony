# Goal

Create a fun, catchy, Dixieland style jazz piece. Like a document for playable music. It can be MIDI, or MusicXML, or ABC Notation, or whatever format you think works best for you. Whatever allows you to express the creativity that you need for this kind of task. You can use Python libraries, or online inspiration, or web libraries, or even visualization tools if that helps. You are the composer.

Start with finding inspiration. Come up with an idea or image or whatever you think you can lock your focus on to help conjure inspiration.

Next, explore ideas, music theory, music knowledge, and practical advice for how to translate that into written, playable music.

Then, plan a scaffolding for the overall structure of the piece. How do you want to approach it? Do you want any tools to help you along the way? What emotions and moments do you want to visit throughout the composition? What core ideas and key effects do you want to achieve?

Then, build it! Make it something to be proud of! Show off - have fun! Make it yours. Write melodies, find chord progressions that you want. Fill in instruments.

Remember to self assess. You are an LLM. You know *how* to do this, but you are not typically trained for this shape of task. Think about how your output will appear and how that compares to a real, playable Dixieland jazz piece. You are smart - if you need to, go up a meta level. Be ambitious and practical. Think things through. Make something meaningful to you.

A couple tips:
1. Use files to help you think and structure your thoughts and work. Use the docs folder if you like. Make other folders if that suits you.
2. The piece should be at least a few minutes long
3. The composition should have Dixieland style jazz instrumentation. Sousaphone, saxophone, trumpet, etc. Start from there if you are looking for inspiration.
